# Downloads and installation

C÷ is intended to be usable without Git knowledge or a GitHub account.

## Source archive

The main branch can be downloaded directly as a ZIP file:

[Download C÷ source ZIP](https://github.com/floppylib/C-Divide/archive/refs/heads/main.zip)

This archive is generated by the hosting service. You do not need to clone the repository or create an account.

## Ready-to-run tools

The project has a release workflow that can build command-line tools for Windows x64 and Linux x64 when a version tag is published. Until the first release exists, there are no official prebuilt packages to download.

[Open the Releases page](https://github.com/floppylib/C-Divide/releases)

The current source build can inspect tokens, check syntax, and compile the supported C÷ subset to a native executable using a host C++20 compiler. This backend is an early preview, not the complete C÷ 1.0 toolchain.

## Install from a local build

Linux:

~~~sh
./scripts/install.sh build/cdiv
~~~

Windows PowerShell:

~~~powershell
.\scripts\install.ps1 -BinaryPath .\build\Release\cdiv.exe
~~~

Both scripts install to the current user's profile by default and do not require administrator permissions.

## Other hosting options

A public source archive and release assets can be downloaded without a GitHub account. A separate mirror on another hosting service may be added later; no independent mirror is configured today.
