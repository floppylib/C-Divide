# Security policy

## Supported versions

At this early stage, only the latest code on the main branch is actively maintained. There are no stable binary releases yet.

## Reporting a vulnerability

Please do not publish exploit details, private data, or weaponizable proof-of-concept code in a public issue.

Use GitHub's private vulnerability reporting feature on the repository's Security tab when it is available. If private reporting is not enabled, contact the maintainer through the contact options on the project owner's profile and ask for a private reporting channel without including sensitive details in the public request.

Please include the affected commit or version, the impact, reproduction steps, and any suggested mitigation. We will acknowledge reports and coordinate a fix and disclosure where possible.
