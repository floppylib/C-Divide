# Code of Conduct

C÷ is a learning-friendly and collaborative project. We want contributors and users to feel safe asking questions, reporting bugs, and sharing ideas.

## Expected behavior

- Be respectful and welcoming.
- Critique ideas and code, not people.
- Explain disagreements with patience and evidence.
- Welcome newcomers and people with different experience levels.
- Give constructive feedback and accept it gracefully.

## Unacceptable behavior

- Harassment, insults, threats, or discrimination.
- Deliberate intimidation or personal attacks.
- Publishing another person's private information without permission.
- Sustained disruptive behavior that prevents others from participating.

## Reporting

For a sensitive report, do not publish private information in a public issue. Contact the repository maintainers through the contact options on the project owner's GitHub profile. Security issues should follow SECURITY.md.

Maintainers are expected to handle reports fairly, confidentially where possible, and proportionately.
