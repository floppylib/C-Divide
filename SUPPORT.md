# Getting support

Before asking for help:

1. Read docs/getting-started.md.
2. Check docs/faq.md.
3. Search existing issues for the same problem.

For a reproducible bug, open a bug report and include your operating system, compiler and CMake versions, the exact command, and the complete error output.

For language-design questions, use a feature proposal and include a short .cdiv example.

Please do not include passwords, private keys, personal data, or security-sensitive details in public issues.
